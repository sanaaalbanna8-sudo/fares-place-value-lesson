# درس فارس: تمثيل الأعداد ضمن منزلتين

عرض تفاعلي للصف الأول — مخصّص لـ **فارس معيقل الخليفات**.

## كيف تشغّله؟

1. افتح الملف `index.html` في متصفح Chrome أو Edge (نقرة مزدوجة).
2. للأفضل: اضغط F11 لملء الشاشة.
3. تنقّل بالأسهم أو أزرار أسفل الشاشة.
4. فعّل الصوت من زر 🔊 (المتصفح يحتاج نقرة أول مرة للسماح بالصوت).

## ماذا يوجد في العرض؟

- شريحة ترحيب ونهاية باسم فارس وصورته المعدّلة
- شرح الآحاد والعشرات مع حركة تكديس المكعبات لتكوين عشرة
- تمارين: كتابة، سحب وإفلات، اختيار، توصيل، تصحيح خطأ سلمى، عدد حر
- أصوات احتفال وسبايدر مان كرتوني

## صوت فارس (الشريحة الأخيرة)

- الملف: `assets/fares-voice.mp3` (تسجيل فارس بعد حذف الفراغات وتحسين الصوت ورفع مستواه).
- يشتغل تلقائيًا بعد ثانية من دخول الشريحة الأخيرة، وفيه زر **🎙️ اسمع رسالة فارس** للإعادة.
- يتوقف تلقائيًا لو رجعت لشريحة ثانية أو كتمت الصوت 🔇.
- أثناء الكلام: صورة فارس تنبض بتوهّج ورسم أعمدة صوت متحرّك.

## نص صوت فارس (النهاية)

انسخه من الشريحة الأخيرة أو من هنا:

> مرحباً أصدقائي! أنا فارس معيقل الخليفات.
> خلّصنا درس الآحاد والعشرات… يا رب تكونوا فهمتوا الدرس!
> تذكّروا: العشرة يعني عشرة مكعبات فوق بعض، والآحاد مكعبات لوحدها.
> شكرًا لمتابعتكم… إلى اللقاء!

## الملفات

- `index.html` — العرض
- `styles.css` — الألوان والحركات
- `app.js` — التفاعل والأصوات
- `assets/fares-hero.png` — صورة فارس بالخلفية المستقبلية
- `assets/fares-voice.mp3` — صوت فارس في النهاية
